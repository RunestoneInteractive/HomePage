Its been a huge summer of changes, probably our biggest in many years, maybe even ever!  Some stats for you:
With 21 contributors we have added 118,654 lines of code, and delted 83,551.  That is not counting about 300,000 lines of code related to removing web2py, jquery, and bootstrap from the code base.  We have added Nine new text books!

## Some Highlights

* New registration and login flow
* New grading page to complement the assignment builder
* New grade book page
* A new Assignment summary report
* Student assignment pages flow with the book better
* Real Time grading improvements for LTI 1.1 and 1.3
* Accessibility improvements throughout the site
* Integration with Study Clues - a smart tutor available 24x7 (available for a limited number of courses)

### New Textbooks

* Active Prelude to Calculus
* Introduction to AI and Robotics
* Calculus and Analytic Geometry IV
* Active Calculus with Doenet
* Applied Precalculus
* Introduction to Engineering
* Game Programming with GDScript
* AI for All
* Python Programming: Interactivity and Ethics
* Java for Python programmers has been significantly revised
* Python for Everyone has been significantly revised and ported to PreTeXt

## What we Left Behind

* The old web2py server
* The Practice Feature
* The old student progress dashboard

Thanks to the entire community for all the work!
